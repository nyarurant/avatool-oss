# PatchNote 1.0.340

新機能
- サイドバーに「衣装解析」ボタンを追加しました。ダウンロード済みだが未解析のアイテムがある場合、件数をバッジ表示し、そのアイテムのみを対象に解析を実行できます。

UI改善
- アバターフィルターを画像付きドロップダウンへ刷新しました。アバター名だけでなくプレビュー画像を見ながら対象を選択できるようになり、絞り込み操作の視認性を改善しました。

仕様変更
- アバター解析済みでも対応アバターが0件のアイテムは「未解析」扱いとし、再解析を促すようバッジカウントに含めるよう変更しました。

不具合修正
- アバター情報の未解析状態でも、フィルター操作から解析実行へ遷移できるように挙動を調整しました。
- フィルターの開閉状態と選択状態の同期を見直し、操作後に状態が残るケースを修正しました。
