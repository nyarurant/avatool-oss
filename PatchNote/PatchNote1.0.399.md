# PatchNote 1.0.399

不具合修正

- 対応アバターの判定精度を改善しました。
- 商品説明やタグ、販売ページ上の選択肢だけで、未確認の対応アバターが付いてしまうことがある問題を修正しました。
- 再同期後、古い自動判定が残って対応アバターとして表示され続けることがある問題を修正しました。
- BOOTHログイン直後のダウンロードで client.get is not a function エラーが連続して出ることがある問題を修正しました。

改善

- 一括ダウンロードを 30 件ずつに制限しました。30 件を超える場合は、バッチ完了後に残りを再実行するよう案内します。

UI改善

- バックグラウンドインポートのモーダルを改善しました。
  - モーダルタイトルを「バックグラウンドインポート」に変更し、バッチ時はパッケージ件数を表示するようにしました。
  - インポートの進行状況を「準備中 → ドライラン実行中 → 依存確認中 → インポート送信中 → 完了 / エラー」のフェーズインジケーターでリアルタイム表示するようにしました。
  - プログレスバーを見やすい太さに変更しました。
  - ボタンを整理しました。「実行」を「インポート開始」に改名し、重複していた「閉じる」と「キャンセル」を1つにまとめ、処理中・完了・エラーで表示されるボタンを状態に応じて切り替えるようにしました。
- パッケージ選択モーダルのインポートモード選択を改善しました。
  - ライブ / バックグラウンドの選択をタイルボタン形式にし、各モードの説明文を追加しました。
- ダウンロード対象選択モーダルの両ボタン（未DLのみ・全アイテム）の枠と背景が暗いUIで目立ちすぎていた問題を修正しました。
