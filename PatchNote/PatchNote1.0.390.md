バージョン 1.0.390

不具合修正・改善

- ヘルスチェック機能に Unity Editor とVCC（VRChat Creator Companion）の存在確認を追加
  - 設定済みの Unity Editor パスが実際に存在しない場合に警告を表示するようになりました
  - VCC がインストールされていない（settings.json が見つからない）場合に警告を表示するようになりました
  - 起動時の自動チェックおよび設定画面からの手動チェック時に確認されます

不具合修正

- 同じ販売者の複数アイテムをインポートした際に、フォルダアイコンが別アイテムの画像になる問題を修正しました
  - インポート時のフォルダ名にアイテム ID を付加するようになりました（例: mochipun__6177489）
  - これにより各アイテムのフォルダが一意に識別され、正しいアイコン画像が表示されます

- 同じアイテムの複数パッケージをインポートした際に余分なフォルダが残る問題を修正しました
  - 同じアイテム ID のパッケージはすべて同一フォルダに統合されるようになりました
  - 再インポート時に既存フォルダと新規フォルダが分離して2つになる問題を解消しました

- アバター解析中に新たなダウンロードをキューに追加すると、その後キューが進まなくなる問題を修正しました
- ダウンロードまたは展開中にリストをスクロールするとダウンロードボタンが誤って有効化される問題を修正しました
- ダウンロードが失敗した際にタイルが「ダウンロード中...」のまま固まる問題を修正しました（失敗直後に表示が戻るようになりました）

内部改善

- Unity プロジェクトへのスクリプト書き出し処理を改善しました（内部変更）
- SimpleFolderIcon のインストール方式を変更しました
  - アセットインポート時に SimpleFolderIcon が Unity プロジェクトへ正しくインストールされるようになりました
- Unity バッチインポート中の IPC 通信にタイムアウトを設定しました
  - Electron 側が異常状態のときに Unity のインポート処理が長時間停止することがある問題を修正しました
 
ダウンロード安定性
- アイテムのダウンロード完了後にメタ更新やアバター解析で一時的なエラーが起きても、完了済みのダウンロードが失敗扱いにならず、キューが安定して次へ進むようにしました。
- 開発・検証用に、実ダウンロードなしでキュー表示、進捗表示、完了表示、失敗表示、設定画面をスクリーンショット付きで確認できる UI probe を追加しました。
- ダウンロードが途中で切断された場合に、不完全なファイルが完成品として残らないようにしました。
- 既存の ZIP が壊れている場合はスキップせず、再ダウンロードするようにしました。
- 対応アバター解析の詳細結果が、解析後のカード表示やプレビュー画面に正しく反映されない問題を修正しました。
- ダウンロード後の自動アバター解析結果が、Ctrl+R や再起動を待たずカード上の対応アバター表示へ反映されるようにしました。
- ダウンロード直後の解析更新で、インポート可能なアイテムのボタンが一時的に「ダウンロード」へ戻ることがある問題を修正しました。
- ダウンロード完了、更新確認、対応アバター候補の確定/未判定戻しの直後に、一覧の絞り込み結果やカード表示が古いまま残ることがある問題を修正しました。
- 「失敗した項目を再試行」を実行した際に、再試行回数がリセットされず即座に再度失敗扱いになることがある問題を修正しました。
