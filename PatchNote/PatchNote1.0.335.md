# Patch Note 1.0.335

- ダウンロード完了後に進捗バーが残り、ボタンが「ダウンロード」のままになる場合がある問題を修正しました。キュー完了時にUI状態を自動復旧し、必要に応じて一覧を再同期するよう改善しました。
- 再読み込み時のカード描画を安定化し、不要な二重再描画を削減して画面の揺れを抑制しました。

- キュー完了時の状態同期を全体再描画から差分同期へ変更し、カード全体の再生成による画面の暴れを抑制しました。

- ダウンロード進捗バーの表示方式をレイアウト固定化へ変更し、進捗更新中のカード全体の揺れを抑制しました。

- 起動時/自動インポート完了時の状態反映を全体再読み込みから差分同期へ変更し、一覧全体の揺れをさらに抑制しました。

- ダウンロード完了時に一部ケースで全体再描画が走る経路を除去し、グリッド表示での完了直後の暴れを抑制しました。
