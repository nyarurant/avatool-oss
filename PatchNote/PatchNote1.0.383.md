# PatchNote 1.0.383

アバター絞り込み精度を改善しました。

- アバター解析の速度が改善されました（2回目以降の解析でファイルが変わっていないアイテムは解析をスキップ）
- アバター絞り込みで複数のアバターを同時に選択できるようになりました（例: シオとルルネを同時に絞り込み）
- アバター絞り込みパネルで複数アバターを選択してもフィルタが機能しない問題を修正しました
- アセットカードに対応アバターのサムネイル画像バッジを表示するようになりました（画像がない場合はアバター名の頭文字を表示）
- フォルダプレビューのUIを改善しました（ボタンをヘッダーバーに統合・アイコン追加、ファイル一覧・ツリーのホバー/選択ハイライト追加）
- 対応アバターの検出精度が向上しました
- アバター本体アイテムが他のアバター名で絞り込まれてしまう問題を修正しました（例: しおちゃんでショコラ絞り込みに表示される）
- 多アバター対応テクスチャ・メイク系アイテムで、購入していないアバターが絞り込み対象に含まれる問題を修正しました
- 武器・ギミック・小道具系アイテムがアバター絞り込みに表示されなくなりました
- 設定の変更が次回起動後に反映されないことがある問題を修正しました
- ZIP 展開に失敗したファイルが「展開済み」として扱われ Unity インポート候補に欠けが生じる問題を修正しました
- 前回のフォルダリネーム計画が次回インポートに混入する問題を修正しました
- 衣装解析の候補確定ボタンと「未判定に戻す」が反映されない問題を修正しました
- BOOTH ダウンロード開始時のログイン/クライアント初期化が同時に複数走る問題を防止しました
- 設定保存に失敗した場合に成功扱いにならないよう修正しました
- Unity のバックグラウンドインポートが固まった場合にタイムアウトしてロックを戻すようにしました
