# PatchNote 1.0.426

## 新機能

- アセットプレビューに3Dモデル表示・回転機能を追加しました（ベータ機能、設定の「実行環境」からON/OFFできます）。Unityを起動しなくても、.fbx/.objファイルや.unitypackage内のモデルをその場で表示してマウスで回転・拡大縮小しながら確認できます。マテリアル・シェーダー（Poiyomi等のカスタムシェーダーを含む）は再現されないため、実際の見た目とは異なる場合があります。

## 修正

- パスワード付きzip/7zアーカイブのダウンロード時に、パスワード入力を求める画面が正しく表示されず処理が失敗することがある不具合を修正しました。
- 緊急アップデート時に、更新ファイルの検証情報が不完全な場合はインストーラーを実行しないよう安全性を強化しました。
