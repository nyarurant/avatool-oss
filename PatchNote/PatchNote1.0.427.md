# PatchNote 1.0.427

## 新機能

- アセットプレビューに3Dモデル表示・回転機能を追加しました（ベータ機能、設定の「実行環境」からON/OFFできます）。Unityを起動しなくても、.fbx/.objファイルや.unitypackage内のモデルをその場で表示してマウスで回転・拡大縮小しながら確認できます。
- 3Dプレビューに「Expressions」パネルを追加しました。VRChatのExpression Menu／SubMenu／Toggle／Buttonを操作でき、左右のハンドジェスチャー入力と組み合わせてAnimator Controllerの状態、GameObject表示、表情BlendShapeをモデルへ反映できます。
- 3Dプレビューに「Animations」パネルを追加しました。パッケージ内のAnimationClipを検索し、再生／停止／Loop／速度変更／シークしながら全身ポーズや小物アニメーションを確認できます。Humanoidポーズは初回だけバックグラウンドのUnityで高精度変換し、以後はキャッシュから再生します。
- ExpressionsパネルのRadial／Two Axis／Four Axis Puppetに対応しました。スライダーまたはXYパッドを操作すると、Time Parameterや1D／2D／Direct BlendTreeを通して表情・体型・マテリアル等のAnimation Curveを連続的に反映します。
- 3Dプレビューで、パッケージ内の `.mat` からマテリアル設定を読み取り、lilToon 系機能を広く近似表示します（完全一致ではありません）。
  - メイン色/テクスチャ、HSVG 調色、Main2nd レイヤ、1〜3影（色・境界・ぼかし・影色テクスチャ）、リム、バックライト、MatCap、法線、アルファマスク、発光、アウトラインなど
  - 色違いマテリアルがある場合はドロップダウンで切り替えできます
- 3Dプレビューに簡易「服を着せる」機能を追加しました。「＋ 服を着せる」ボタンからダウンロード済みの別アイテムを選ぶと、表示中のアバターに重ねて表示できます（ボーン名が一致する部分のみをフィットさせる簡易実装のため、体型が大きく異なる組み合わせでは位置がずれることがあります）。
- 設定に「AI連携」を追加しました。Claude Code / Codex CLIとAvatoolを連携でき、「自動セットアップ」を押すだけで両CLIへ連携用の設定が登録されます。連携後は、AIエージェントからライブラリ検索・BOOTH検索・ダウンロード・Unityインポート・設定変更などをAvatoolの外から直接指示できるようになります。セットアップはボタンを押した場合のみ実行され、自動では行われません。

## 改善

- 3DプレビューとExpressionsを静止している間は再描画・Animator再評価を停止し、CPU/GPU負荷を大幅に軽減しました。時間AnimationはExpressions右上の再生ボタンを押した時だけ動作します。
- AnimationClipの位置・回転・拡縮、Humanoid muscle、BlendShape、表示切替、マテリアルカーブを同じローカルRuntimeで合成し、Constraintと軽量PhysBoneを続けて評価するようにしました。
- AnimationClip再生は画面更新に合わせて最大60fpsで評価し、Transformのパス解決結果を再利用することで、大きなアバターや長いClipでも滑らかさと負荷を両立しました。
- AFK等の寝姿勢はClip選択・シーク時にカメラを自動調整し、アバター全体の移動を含むClipは画面内で確認できるインプレース再生にします。
- 3Dプレビューで、Prefabに含まれるVRC Avatar Descriptor、PhysBone、Contact、Constraint、Expression、Animator Controller／Animation Clip設定を解析し、検出したVRCSDK要素を画面左下に表示するようにしました。
- 3DプレビューにUnityを起動せず動作する軽量PhysBone互換Solverを追加しました。PrefabのPhysBone／Collider設定を読み取り、髪・尻尾・衣装などへ疑似風を与えてその場で揺れ方を確認できます。
- 軽量PhysBone互換SolverはPull／Spring／Stiffness、重力、Stretch／Squish、Angle／Hinge／Polar制限、Sphere／Capsule／Plane Collider、Ignore Transform、Multi Childを反映します。
- 3DプレビューでVRC Position／Rotation／Scale／Parent／Aim／LookAt ConstraintをUnityなしで反映する軽量Runtimeを追加しました。
- 3DプレビューでVRC Contact Sender／Receiverを評価し、Constant／OnEnter／Proximityの値をExpressionsパラメータへ反映する軽量Runtimeを追加しました。
- 3DプレビューのExpressionsにEye Look／まばたき／LipSync確認欄を追加しました。Avatar Descriptorの視線角度、Eyelid BlendShape、15種のVisemeをUnityなしで動かして確認できます。
- Eye Look確認にEyelid Bones形式と自動Blink／Saccadeを追加しました。BlendShapeまぶたを使わないアバターでも、Avatar Descriptorの上下まぶた姿勢を確認できます。
- ExpressionsにHumanoid姿勢確認を追加しました。頭の向き、腕の簡易IK、しゃがみと足の接地をUnityなしで操作し、Tracking ControlがAnimation指定の部位はAnimatorを優先します。
- VRC Animator Tracking Controlへ対応し、Eyes／MouthがAnimation指定のステートではEye Look／LipSyncよりAnimatorを優先するようにしました。
- VRC Playable Layer Control／Animator Layer Control／Animator Locomotion Control／Animator Temporary Pose Space／Animator Play Audioを解析・評価し、レイヤーWeight、Locomotion停止、Pose Space、AudioイベントをExpressionsのローカルRuntimeへ反映するようにしました。
- VRCSDK解析結果は選択中Prefabの件数を表示するよう改善し、別PrefabのPhysBone等が合算されないようにしました。
- 3Dプレビュー（beta）: FBX が `.unitypackage` 内にある場合は、パッケージ本体を選択してプレビューする旨を UI に明示。タイルに「3D」バッジ、ダブルクリックでもプレビューを開けるようにしました。
- 3Dプレビューで `.unitypackage` を展開する処理をバックグラウンドスレッドに移し、展開中にアプリが「応答なし」になる問題を緩和しました（初回展開は時間がかかることがあります）。
- 3Dプレビューの見た目を調整: アウトラインの二重変形修正、テクスチャUV向き、誤ったMatCap加算による白飛び、影・リムの過剰効果を抑制、影の境界を柔らかくして単一光源特有の硬い陰影を緩和。
- 3Dプレビューのテクスチャずれを修正（Unity PNG の flipY、アルファマスク、過剰トーンマップによる帯状の見た目）。
- 全身アバター等で白抜けしやすかった問題を修正: Material 型の `.asset` も抽出、Prefab の部位ごとマテリアル割当を強化、不透明マテリアルの誤カットアウトを修正。
- 3Dプレビューで Prefab のマテリアル割り当て（SkinnedMeshRenderer / MeshRenderer）を読み取り、FBX デフォルトではなく Prefab が参照する `.mat` とテクスチャを使うようにしました。
- 3Dプレビューは **Prefab 基準**で表示します（上部の Prefab 一覧から選択）。髪色分けなど複数 Prefab がある場合は Prefab 切替で色が変わります。
  - Prefab が無いときだけ FBX/メッシュ一覧になります。
- Windowsログイン時の自動起動を設定からON/OFFできるようにしました（初期値はOFF）。
- アプリ更新の自動確認をON/OFFできるようにしました。
- 更新ファイルは自動ダウンロードせず、ユーザーの明示操作で取得するようにしました。
- 依存関係を更新し、安全性を改善しました。

- 既存の3Dプレビューキャッシュでは位置・回転・拡縮カーブが読み込まれない問題を修正しました。unitypackage全体を再展開せず、AnimationClip解析キャッシュだけをバックグラウンドで一度更新します。
- Humanoid AnimationClipの全体移動値をHipsのローカル座標として誤適用し、再生中のアバターが画面外へ飛んで消える問題を修正しました。
- 大きく姿勢が変わるAnimationClipの再生・ループ・シーク後に、モデルが描画範囲判定から外れたりカメラ座標が壊れたりして表示されなくなる問題を修正しました。
- 選択中のPrefabに存在しない小物向けTransformカーブがアバター全体へ誤適用され、モデルが遠くへ移動したり大きさ0へ縮んだりする問題を修正しました。

- 3DプレビューのAnimationsパネルで、一部のAnimationClipを再生すると腕や脚が異常に伸びたように表示され、ポーズが破綻して見える不具合を修正しました。
- Humanoid AnimationClipの`Forearm Stretch`／`Lower Leg Stretch`を長さ変更と誤解して無視していたため、肘と膝が曲がらず不自然なポーズになる問題を修正しました。Unityと同じく、伸び切った姿勢を基準にした肘・膝の屈曲として再生します。
- Humanoid AnimationClipを斜め・背面・上下から見ると、腕や脚の左右、手首、指、腰の向きがUnityと異なる問題を修正しました。選択したPrefabとClipをUnity基準で60fps変換し、骨名のL/R表記ではなくHumanoid骨IDと実際の左右位置で全身へ反映します。
- AnimationsパネルでLoopをOFFにしても、Loop指定されたClipを終端までシークすると先頭フレームへ戻ってしまう問題を修正しました。
- 3Dプレビューで、素体Prefabと衣装Prefabを組み合わせて1体を構成するアバターを開くと、衣装が表示されず素体だけになる不具合を修正しました。複数のFBXを同じアバターとして重ね、Animation・PhysBone・Constraintも親Prefabから継承して確認できます。
- 3Dプレビューの読み込みが完了せず「読込中」の表示のまま先に進まなくなることがある不具合を修正しました。展開処理が結果を返さずに終了した場合でも、エラーとして扱って再試行できるようになります。
- PhysBoneを停止した直後にもう一度開始すると「Unityプロジェクトが使用中」となって開始できないことがある不具合を修正しました。停止時は前回のUnityが終了するまで待ち、開始時も使用中であれば解放を待ってから起動します。
- PhysBoneやAnimationClipの変換で使う内部Unityプロジェクトの整理が、ボーン対応表のキャッシュ用プロジェクトまで削除してしまい、一度作成済みでも毎回Unityの起動からやり直しになる不具合を修正しました。
- 同じアバターに対してAnimationClipの変換やボーン対応表の作成が同時に走ると、Unityが二重に起動して失敗することがある不具合を修正しました。同じプロジェクトを使う処理は順番に実行されます。
- 古いプレビュー用プロジェクトの整理に失敗しただけで、PhysBoneやAnimationClipの変換自体が開始できなくなる問題を修正しました。整理の失敗は記録のみ行い、プレビューはそのまま利用できます。
- PhysBoneの再生中やプレビューの準備中に、アプリの操作が一時的に引っかかることがある問題を改善しました。Unityとのやり取りやプレビュー用フォルダの容量確認を、画面の動作を止めない方式に変更しています。
- 3Dプレビューが使用した一時ファイルが削除されず、使うたびにディスク使用量が増え続ける問題を修正しました。失敗時のログは調査用に残しつつ、古いものは自動的に削除します。
- Unityが複数バージョンインストールされている環境で、3Dプレビューの一部機能がお使いのプロジェクトとは異なるUnityバージョンを選んでしまうことがある問題を修正しました。登録済みUnityプロジェクトのバージョンを優先して選択します。

- Unity インポート履歴、実行ログ、アプリ更新の確認も MCP に追加しました。更新確認ではダウンロードやインストールは開始しません。
- 自動セットアップはAvatoolが配置したSkillだけを更新し、同名のユーザー作成Skillや手編集されたSkillは上書きしません。
- Codex / Claude Code の状態確認に時間がかかる環境でも、設定画面を待たずにすぐ開けるようにしました。
- Codex CLIでAvatool MCPが正しく登録されていても、設定画面で「登録内容が不一致」と表示される問題を修正しました。
- MCPからのVPM依存関係解析で、対象のUnityPackageを実際に走査しないことがある不具合を修正しました。
- MCPのほしいものリスト更新で、BOOTHへの反映に失敗しても成功と表示される不具合を修正しました。同期できなかった場合は、ローカル更新済みであることを含めて失敗を通知します。
- MCP bridgeの接続先をローカルの正規endpointに限定し、認証tokenが意図しない接続先へ送られないようにしました。
- MCP操作にtimeoutを設け、bridgeや外部通信が応答しない場合に無限に待ち続けないようにしました。
