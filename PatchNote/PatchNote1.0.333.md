# Patch Note 1.0.333

- 起動時の自動処理まわりで、ダウンロードと自動インポートの進行表示および完了判定の安定性を改善しました。
- 起動時の自動ダウンロード中にセッション切れで `download_not_file_response: text/html` が発生した場合、ログインフローを自動で起動して続行できるように改善しました。
- ログイン画面が表示直後に閉じる場合がある問題を修正し、認証確認に成功した場合のみログインフローを完了するよう改善しました。
- ログインウィンドウ右下にオーバーレイの「ログイン完了」ボタンを復活し、手動完了操作ができるようにしました。
- アプリ更新チェックで `latest.yml` のリリースノート読み込みに失敗する場合がある問題を修正しました。
- リリースノート生成時に文字化け行を自動除外する対策を追加し、更新情報表示の可読性を改善しました。
- ログインウィンドウの「ログイン完了」ボタン押下時の検知方式を改善し、ボタン操作で完了判定が確実に走るよう修正しました。
- ダウンロードキューIPCの初期化不整合を修正し、`setQueueSender is not a function` エラーで処理が止まる問題を解消しました。
