# PatchNote 1.0.423

## 改善

- BOOTHクライアントの「ほしいリスト」タブに「外す」ボタンを追加し、ライブラリの詳細モーダルを開かなくても、その場でほしいリストから削除できるようにしました。

## 修正

- BOOTHクライアントのホーム画面「最近の注文」・「注文履歴」タブに、購入していないほしいリストのアイテムが紛れ込んで表示されてしまう問題を修正しました。既存データも自動的に補正されます。
- 対応アバターの自動解析で、フォルダ名からの一致判定がぎりぎり基準に届かず、対応アバターが正しく検出されないことがあった問題を修正しました。
- アバター絞り込みの選択肢を、「実際に購入したアバター本体」だけに限定するよう変更しました。これまでは、対応を謳っている衣装・アクセサリーを持っているだけで（アバター本体は未購入でも）そのアバター名が選択肢に出てしまっていました。なお、絞り込みを選択した際に表示される対応アイテム自体は、これまで通り対応衣装・アクセサリーも含めて表示されます。
