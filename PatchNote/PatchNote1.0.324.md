# Patch Note 1.0.324

- 変更内容をここに記載

- 参考: PatchNote1.0.323.md
- アップデート完了ダイアログの表示を整理し、「完了メッセージ」「version」「更新内容」を分けて見やすくしました。
- 更新内容の表示で先頭の箇条書き記号（例: `-` や `1.`）がそのまま見える場合がある問題を改善しました。
- 更新内容テキストで `\n` や `<br>` を改行として解釈し、長文でも読みやすく表示されるようにしました。
- 通常の `latest.yml` 解析に失敗した場合でも、`latest-backup.yml` から更新情報を取得して継続できる緊急アップデート経路を追加しました。
- 緊急アップデート経路では、更新ファイル（EXE）を直接ダウンロードして更新実行できるようにしました。
- リリーススクリプトで `latest-backup.yml` を自動生成し、成果物と一緒にアップロードするようにしました。
