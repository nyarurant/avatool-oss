# PatchNote 1.0.406

新機能

- BOOTHの無料ダウンロード履歴をライブラリに取り込むようにしました。ライブラリ同期時に「ライブラリ > 無料ダウンロード」の作品が自動で追加され、カテゴリフィルタの「Free」から絞り込んで確認できます。

改善

- BOOTHの無料ダウンロード履歴に新しい作品だけが増えた場合でも、ライブラリ同期後に一覧へ反映されるようにしました。
- インポート操作の詳細をログファイル（unity_import.log）に記録するようにしました。インポート開始・VPM パッケージのインストール結果（成功/失敗）・完了・エラーが記録されます。
- ライブインポート開始時にログ出力処理の不整合でインポートが進まない場合がある問題を修正しました。
- 一括インポートでVPM自動インストーラー系パッケージを含めたとき、installer処理で止まる場合がある問題を修正しました。
- パッケージ選択モーダルからのライブ一括インポートでも、VPM/installer系パッケージをUnityへ直接渡さず、Avatool側でVPM導入してから通常パッケージだけをUnityキューへ送るようにしました。
- 一括インポートのパッケージ選択でVPM/installer系パッケージが最新候補になった場合、本体のunitypackageも初期選択されるようにしました。installerだけが選ばれてUnity側に本体アセットが入らない状況を防ぎます。
- Unityインポート後、既存フォルダ退避中にUnityが退避先フォルダを更新した場合でも、`__avatool_backup_...` のまま残さず本来の管理フォルダ名へ戻すようにしました。
- ライブインポートではUnity側のフォルダ作成完了後にSimpleFolderIconのアイコン書き込みを再試行するようにしました。インポート直後にフォルダ未検出でアイコンが付かない場合を減らします。
- ライブインポート中にUnityのドメインリロードが発生しても、処理中パッケージとリネーム計画を復旧し、インポート後のフォルダリネームと完了ログ記録を続行するようにしました。
- パッケージ選択モーダルのライブインポート成功時のメッセージが「成功 0件 / 失敗 0件」と誤表示される問題を修正しました。キューに追加した件数を正しく表示するようになります。
