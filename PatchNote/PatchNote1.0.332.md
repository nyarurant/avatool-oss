# Patch Note 1.0.332

- このバージョンにユーザー影響のある変更はありません。（内部運用ルール更新のみ）

- 設定保存処理の不具合を修正し、設定変更が再起動後に戻ってしまうケースを改善しました。
- Cookie の保存先をアプリデータ配下に統一し、設定保存時に不整合な Cookie パスが残らないようにしました。

- BOOTH無料アイテムの判定ロジックを改善し、価格表記やラベル表記の揺れで無料ダウンロードが検出されないケースを修正しました。
- 自動インポート設定の保存処理を修正し、`Folder Icon Bootstrap` のON/OFF設定が意図せず上書きされる問題を修正しました。
- 無料価格判定ロジックの互換性を拡張し、`0` / `¥0` / `￥0` / `0円` / `0.0` などの表記揺れでも無料として扱えるよう改善しました。
