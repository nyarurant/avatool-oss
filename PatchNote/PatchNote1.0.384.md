# PatchNote 1.0.384

フォルダプレビューのUIを全面的に改善しました。RAR/7z ファイルの展開に対応しました。

- ファイル一覧にサムネイル表示を追加しました（PNG・JPG 等の画像は実際の画像を表示）
- ファイル・フォルダを選択したときにファイル名と種別を正しく表示するよう修正しました
- プレビュー右パネルの初期表示をアセットの BOOTH サムネイルに変更しました
- ファイル一覧タイルのデザインを見やすく改善しました（アイコン大型化・拡張子バッジ追加）
- フォルダツリーとプレビューパネルのレイアウトを最適化しました
- RAR・7z ファイルのダウンロード後展開に対応しました（7-Zip がインストール済みの場合）
- パスワードで保護された ZIP ファイルを展開する際にパスワード入力ダイアログを表示するようにしました

UI改善
- 検索ボックスへの入力時にアセット一覧の再描画をまとめて処理するようにしました（キー入力ごとに即座に再描画していた動作を改善）
- 同じ絞り込み条件での連続した再描画を省略するようにしました
- 日付の解析処理をキャッシュするようにしました
- ストレージ使用量の計算結果を30秒間キャッシュするようにしました

インストーラーサイズ削減
- Windowsアプリとして不要なLinux・macOS向け7zipバイナリをビルドから除外しました
- Electron 38がサポートしない32bit・ARM64向け7zipバイナリを除外しました
- ビルドに含まれていた開発用ファイル（ソースマップ・型定義・ドキュメント・テスト）を除外しました
- Avatoolが使用しないaxiosのブラウザ向けビルドを除外しました
- 合計で約43MBの削減を見込んでいます
