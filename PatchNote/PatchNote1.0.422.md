# PatchNote 1.0.422

## 改善

- 「BOOTHほしいリストからインポート」を、より新しく確実なBOOTHの取得方法に切り替え、インポート速度を大幅に改善しました。あわせて、BOOTH側でほしいリストから削除したアイテムは、次回インポート時にAvatool側でも自動的に「未所持」へ反映されるようにしました。
- Avatoolで新しく「ほしいリストに追加」したアイテムは、BOOTH本体側にも反映されるようにし、あわせてBOOTH側に「avatool」という名前のリストを自動作成してそこに登録するようにしました（他のアプリ・手動で追加したものと見分けやすくするため）。

## 修正

- ほしいリストから外れた（未購入の）アイテムが、「すべてのアイテム」など通常の一覧に紛れ込んで表示されてしまう問題を修正しました。
- BOOTHクライアントの商品詳細画面で、バリエーションが名前なし1種類だけの商品（VirtualLens2など）は「カートへ」「購入する」ボタンがそもそも表示されず、購入操作ができなくなっていた問題を修正しました。
- BOOTHクライアントの商品詳細画面で、バリエーション一覧の価格やボタンの表示位置が行によってバラバラにズレることがあったのを、縦に揃うよう表示を整えました。
- 画面下部のステータスバーで、キュー件数・完了件数が重複して表示されていた無駄な表記を整理しました。
- 設定画面のタブ名・項目名の一部が英語のままだったのを日本語表記に統一しました。
- 「無料アセット追加」画面が簡素すぎたため、プレビュー内容（サムネイル・タイトル・作者・ファイル件数）を分かりやすく表示するデザインに刷新しました。
- BOOTHクライアントの「検索」を、モーダルで画面を覆う表示から、「ホーム」「カート」「ほしいリスト」と同じ、サイドバー・上部メニューを維持したまま切り替わる通常のタブ表示に変更しました。
