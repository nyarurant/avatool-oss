# Patch Note 1.0.327

- ZIP展開時の1ファイル上限（既定: 512MiB）を固定値から設定値へ変更し、将来のワールド向け運用に備えました。
- ZIP展開中に上限超過ファイルを検出した場合、スキップ継続か「このZIPだけ上限無視で続行」かを選べる安全確認ダイアログを追加しました。
- `.unitypackage` 解析結果のキャッシュを追加し、同じファイル（パス・サイズ・更新日時が同一）の再解析をスキップして処理を軽量化しました。
- `.unitypackage` のメタ解析をCPUコア数に応じた並列数で実行するようにし、高コア環境での照合処理を高速化しました。
- ZIP上限超過時の確認ダイアログ文面と選択肢を整理し、`キャンセル / 展開する` で判断しやすくしました。
- ZIP上限超過時の確認をOS標準ダイアログからアプリ内モーダルへ変更し、画面遷移なく操作できるようにしました。
