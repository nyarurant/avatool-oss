# Patch Note 1.0.331

- Unity Project を再起動して開き直した直後に、フォルダアイコンがデフォルト表示へ戻ることがある問題を改善しました。
- Project 読み込み時やスクリプト再読み込み時に、フォルダアイコンを自動で再反映するようにしました。
- 自動インポート設定の「Avatool 独自Scriptを導入」から、フォルダアイコン再適用もまとめて制御できるようにしました。
- 自動インポート設定の「Avatool 独自Scriptを導入」にヘルプ表示を追加し、マウスオーバーで導入される補助Scriptの目的を確認できるようにしました。

- 自動インポート設定で Avatool 独自Scriptを導入 が OFF の場合、Unityインポートを実行できないようにしました。
- Avatool 独自Scriptを導入 が OFF のとき、SimpleFolderIcon package を導入 は自動で OFF になり選択できないようにしました。
- 上記条件でインポートを実行した際に、設定をONにする案内メッセージを表示するようにしました。

- OS関連付けインポートの表示文言を見直し、エラー/進捗メッセージを分かりやすい表現へ更新しました。
- OS関連付けインポートの表記を「Scriptインポート（OS連携）」に統一しました。

- インポート画面にドライラン機能を追加し、実行前に有効パッケージ数、リネーム予定、依存不足を確認できるようにしました。
- インポート画面にプロジェクト別プリセットを追加し、プロジェクトごとに『実行前ドライラン』『依存不足の自動導入』を保存できるようにしました。

- 手動ドライラン時に詳細ポップアップを表示し、依存不足・リネーム予定・無効パス・インポート対象を一覧で確認できるようにしました。


- Logs パネルを開いたときに最新ログを再読込するよう改善し、空表示になりにくくしました。

- Unityインポート時のフォルダ重複処理を改善し、同じ itemId のパッケージは同じフォルダへまとまるようにしました。
- 同じ itemId の複数パッケージで発生していたフォルダアイコン競合を起こしにくくし、安定して反映されるようにしました。

- 同じ商品（同一 itemId）を複数パッケージでインポートした際、フォルダアイコン処理が重複しにくいように改善しました。
