# PatchNote 1.0.407

改善

- Unityライブインポートの結果受信が5分タイムアウトした場合に、操作ログへ通知を表示するようにしました。Unityが起動していない場合などに原因を把握しやすくなります。
- 自動ダウンロードの処理中に予期しないエラーが発生した場合、エラー内容を操作ログに表示するようにしました。
- 自動更新チェックが前回の実行中に再度トリガーされても、並列実行せず完了を待つようにしました。
- 操作ログの全削除ボタン押下時に確認ダイアログを表示するようにしました。誤操作によるログ消去を防ぎます。
- Unityプロジェクトをリストから削除する際に確認ダイアログを表示するようにしました。
- アイテムを手動追加する際、URLまたはIDの形式が正しくない場合のエラーメッセージに入力例を追加しました。
- 配布ファイルに開発作業ログや一時デバッグ素材が含まれないよう、リリース成果物の除外ルールを強化しました。
- 対応アバター画像が未登録のアイテムでも、対応アバター名のバッジが表示されるようにしました。
- プレビューモーダルで対応アバター解析パネルと確認待ちレビューの前後移動ボタンが表示されない問題を修正しました。
- 未実装だった「最近使用」フィルターを非表示にし、押しても表示内容が変わらない状態を解消しました。
- 表示フィルターの選択状態が見た目に反映されず、非選択の「すべて」が青く残る問題を修正しました。
- 更新があるアイテムのフィルター名を「更新済み」から「更新あり」に修正しました。
- アイテム末尾の追加タイルに残っていた英語表記を日本語に統一しました。
- 設定画面や補助UIに残っていた英語ラベルを日本語表記へ統一しました。
- ダウンロード対象選択モーダルのホバー表示が CSP により無効化される問題を修正しました。
- アバター絞り込みパネルの画像エラー処理が CSP により無効化される問題を修正しました。
- ライブラリ同期時に調査用のアイテムJSONが自動生成され続ける問題を修正しました。
- アプリ起動時にヘルスチェックが正常終了した場合でも「Health check: error 0 / warn 0」という通知が表示され続けていた問題を修正しました。問題が検出された場合のみ通知が表示されるようになります。
- 手動追加モーダルをアセット一覧の空状態ボタンから開いた場合、前回のプレビュー結果が残ったまま「追加」ボタンが有効になっていた問題を修正しました。
