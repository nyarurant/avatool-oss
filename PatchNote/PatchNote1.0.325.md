# Patch Note 1.0.325

- `latest.yml` が壊れていて通常更新が失敗する場合でも、`latest-backup.yml` から更新情報を取得して続行できる緊急アップデート機能を追加しました。
- 緊急アップデートでは更新EXEを直接ダウンロードし、アプリ内の「更新する」操作からそのまま実行できるようにしました。
- リリース時に `latest-backup.yml` を自動生成して同時アップロードするよう改善し、更新情報の冗長性を強化しました。
- `latest-backup.yml` を避難用の最小構成（`version` / `path` / `sha512`）に整理し、構文エラー要因になりやすい追加項目を持たない形式にしました。
