# PatchNote 1.0.424

## 修正

- Unityへのアセットインポートで、インポートするアイテム数が多いほど不必要に時間がかかっていた問題を修正しました。パッケージを1つ取り込むたびにプロジェクト内の全アセットを強制的に再チェックする重い処理が最大2回走っていたこと、進捗確認のためだけにプロジェクト内の全ファイルを毎回数え直していたことが原因で、まとめてインポートする際に特に影響が大きくなっていました。
- インポート中の進捗バーが、特にサイズの大きいアイテムで長時間ほとんど動かないように見える問題を修正しました。これまではアイテム1つ分の取り込みが完了した瞬間にまとめて進捗が反映される仕組みだったため、取り込みに時間がかかるアイテムほど「終わるまでずっと止まって見える」状態になっていました。取り込み中のアセット1つ1つの完了を検知して逐次反映するよう変更し、進捗バーが実際の作業状況に合わせて滑らかに進むようになります。
