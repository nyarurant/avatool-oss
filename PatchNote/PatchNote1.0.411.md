# PatchNote 1.0.411

新機能

- ほしいリスト: 未購入の BOOTH アイテムをほしいリストに登録できるようになりました。ツールバーの「ほしいリスト」ボタンから URL または ID で追加でき、アイテム情報を自動取得してプレビュー確認してから登録できます。購入後にライブラリを同期すると通常のアイテムとして自動的に切り替わります。

- ほしいリスト 値下げ通知: ほしいリストに登録したアイテムの価格をバックグラウンドで定期チェックし、値下がりを検知するとデスクトップ通知でお知らせするようになりました。通知はライブラリ同期のタイミングで動作します。

- 削除済みアイテム保持: BOOTH で非公開・削除されたアイテムがライブラリ同期時に Avatool から消えなくなりました。「削除済み」バッジが表示され、「削除済み」フィルタで一覧確認できます。再公開されると自動的に通常状態に戻ります。

- ユーザータグ: アイテムプレビューのインスペクターから任意のタグをアイテムに付けられるようになりました。タグはキーワード検索にも反映されます。

- メモ機能: アイテムプレビューのインスペクターにメモ欄を追加しました。関連リンクや購入時の備考などを自由に記録でき、メモの内容もキーワード検索の対象に含まれます。

- タイトル / 作者名コピー: アイテムプレビューのインスペクターにタイトルと作者名のコピーボタンを追加しました。

- ソート設定の保存: ライブラリのソート順がアプリ再起動後も維持されるようになりました。

- BOOTH検索: ツールバーの「BOOTH検索」ボタンから BOOTH のアイテムをキーワードで直接検索できるようになりました。全画面モーダルで開くためライブラリ画面はそのまま背景に残ります。カテゴリ・価格帯・並び替え・在庫ありフィルターに対応しており、ページ番号ボタンで任意のページへ直接ジャンプできます。検索結果のカードをクリックすると詳細パネルが開き、商品画像・バリエーション・タグ・商品説明などを確認できます。詳細パネルから「ほしいリストに追加」「BOOTHで開く」の操作もできます。

- BOOTHほしいリストのインポート: ほしいリスト追加モーダルから「BOOTHほしいリストからインポート」ボタンを使うと、BOOTH アカウントのほしいリストに登録されたアイテムを Avatool のほしいリストへ一括インポートできます。すでに Avatool に登録済みのアイテムはスキップされます。

- BOOTH検索 バリエーション別カートボタン: 詳細パネルのバリエーション一覧に「カートへ」ボタンを追加しました。在庫があるバリエーションごとに個別にカートへ追加できます。

- ほしいリスト バリエーション別カートボタン: ほしいリスト登録済みアイテムのプレビューに表示されるバリエーション価格一覧にも「カートへ」ボタンを追加しました。バリエーションごとに個別にカートへ追加できます。

- カートへ追加後チェックアウトへ自動転送: 「購入する」ボタンでカート追加が成功すると、自動的に BOOTH のチェックアウトページ（支払い方法選択）をデフォルトブラウザで開くようになりました。「カートへ」ボタンはチェックアウトを開かずカートに追加のみ行います。

UI改善

- フィルタータブ（すべて・更新あり・ほしい・削除済み）に件数バッジを追加しました。タブを切り替えなくても各カテゴリのアイテム数が一目で確認できます。

- ほしいリスト追加モーダルのUIを見直し、入力から登録までの流れが分かりやすくなりました。

- ほしいリスト登録済みアイテムのプレビューを未購入商品の詳細画面として見やすいレイアウトに変更しました。価格・登録日・メモ・タグ・解除ボタンを整理し、商品画像の縦横比も修正しました。

- ほしいリストのカードに価格を表示するようになりました。複数バリエーションがある場合はプレビュー詳細で各バリエーションの価格も確認できます。

- BOOTH クライアントのフォロー中ショップ一覧からショップ名をクリックしたとき、全画面検索モーダルではなく BOOTH モード内に商品一覧を表示するようにしました。商品カードにはサムネイル、タイトル、価格、所持済みバッジが表示されます。

- BOOTH クライアントのフォロー中ショップ一覧に、ショップの作者アイコンを表示するようにしました。

- BOOTH クライアントのホームを高密度化し、ライブラリ数、ほしいリスト、更新あり、ショップ数、直近購入日を一画面で確認できるようにしました。最近の注文、更新あり、ほしいリスト、ショップ比率もパネル表示で見やすくなりました。

- BOOTH クライアントのホームに、BOOTHトップページ由来の「3Dモデル」注目商品セクションを表示するようにしました。Avatool の BOOTH ログインCookieを使って取得し、Assetmanager用途から外れやすい漫画・イラスト・グッズ枠は表示しません。

- BOOTH クライアントのホームに「あなたにおすすめの商品」を追加しました。BOOTH の関連商品APIを使い、直近購入アイテムなどをもとに3Dモデル系の関連商品をホーム上部に最大12件表示します。

- BOOTH クライアントのホームに「フォローしているショップの新着」を追加しました。ライブラリ内でよく使っているショップの新着商品をホーム上部に最大16件取得し、選択ショップ以外の商品が混ざらないようショップ識別子で絞り込んで表示します。

- BOOTH クライアント内の商品カードをクリックしたとき、外部ブラウザへ移動せず Avatool 内の詳細ドロワーで商品情報を確認できるようにしました。必要な場合は詳細内の「BOOTHで開く」から公式ページを開けます。

- BOOTH 商品詳細ドロワーを広げ、商品画像・タイトル・説明をより大きく確認できるようにしました。

- BOOTH 商品詳細ドロワーで、メイン画像下のサムネイルから画像を切り替えられるようにしました。左右の画像切り替えボタンも少し大きくしました。

不具合修正

- パスワード付きの 7z / rar アーカイブを展開する際、パスワード入力プロンプトが表示されず展開に失敗していた問題を修正しました。zip と同様にパスワードを入力して展開できるようになります。

- ほしいリストおよび BOOTH 検索詳細パネルの「カートへ」ボタンを押しても「複数のバリエーションがあります」エラーになりカートに追加できなかった問題を修正しました。

- BOOTH クライアント: ライブラリ画面のヘッダーに「ライブラリ / BOOTH」切り替えボタンを追加しました。BOOTH モードに切り替えるとホーム・カート・ほしいリスト・注文履歴の各ビューがサイドバーナビから利用できます。ホームにはライブラリ統計・最近の注文・ほしいリストのプレビューが表示されます。サイドバーのフォロー中ショップ欄にはライブラリから利用頻度の高いショップが自動的に表示され、クリックで BOOTH モード内の商品一覧を開きます。

- BOOTH クライアント: フォロー中ショップの商品一覧に、別ショップの商品が混ざることがある問題を修正しました。BOOTH 検索結果のショップ識別子を読み取り、選択したショップと一致する商品だけを表示します。
