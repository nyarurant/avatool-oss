# PatchNote 1.0.411

新機能

- ほしいリスト: 未購入の BOOTH アイテムをほしいリストに登録できるようになりました。ツールバーの「ほしいリスト」ボタンから URL または ID で追加できます。購入後に同期すると通常のアイテムとして自動的に切り替わります。
- 削除済みアイテム保持: ライブラリ同期時に BOOTH から非公開・削除されたアイテムが Avatool から消えなくなりました。「削除済み」バッジが表示され、「削除済み」フィルタで確認できます。再公開されると自動的に通常状態に戻ります。

不具合修正

- パスワード付きの 7z / rar アーカイブを展開する際、パスワード入力プロンプトが表示されず展開に失敗していた問題を修正しました。zip と同様にパスワードを入力して展開できるようになります。
